# Gobblet Pokelers 攻略ガイド

能力を活用した戦略的プレイのための攻略法をまとめます。

---

## 1. 基本戦略

### 1.1 能力は「切り札」として温存する

能力は **1ゲームにつき1回のみ** 使用可能です。序盤で安易に使わず、勝敗を決定づける場面まで温存することが重要です。

**能力を使うべきタイミング**：
- 自分がリーチ（あと1手で勝利）の状態
- 相手がリーチで、通常手段では防げない場合
- 決定的な盤面優位を作れる場面

### 1.2 駒配置 → 能力のコンボを意識する

新システムでは **駒を置いた後に能力を使用** できます。この2段階アクションを最大限活用しましょう。

```
【基本コンボの流れ】
1. 駒を配置してリーチ状態を作る
2. 能力で相手の対応手段を奪う
3. 相手は対処困難 → 次ターンで勝利
```

### 1.3 サイズ（S/M/L）の使い分け

| サイズ | 特徴 | 使いどころ |
|-------|------|-----------|
| **L（大）** | 全てを覆える最強駒 | 終盤の決め手、重要マスの確保 |
| **M（中）** | Sを覆える汎用駒 | 中盤の攻防、柔軟な展開 |
| **S（小）** | 覆えないが軽い | 序盤の布石、囮、数の優位 |

**重要**: 大きい駒を早く使いすぎると、終盤で選択肢がなくなります。

## 2. 各ラインの能力活用法

### 2.1 草ライン：やどりぎのタネ

**効果**: 相手の駒を次のターン終了まで移動不可にする

#### ベストな使用場面

**パターン1: リーチ封じ込め**
```
自分がリーチ状態のとき：
1. 勝ち筋のマスに駒を配置
2. 相手がそのマスを覆える唯一の駒を「やどりぎ」で固定
3. 相手は対処不能 → 勝利
```

**パターン2: 時間稼ぎ**
```
相手がリーチ状態のとき：
1. 防御の駒を配置
2. 相手の攻め駒を「やどりぎ」で固定
3. 1ターン猶予を得て逆転を狙う
```

#### コンボ例
```
【リーチ + やどりぎコンボ】
盤面:  自 _ _
       _ 相 _
       _ _ _

1. 左下にLサイズを配置（斜めリーチ）
2. 中央の相手駒を「やどりぎ」で固定
3. 相手は中央から動けず、覆うしかない
4. Lサイズは覆えない → 次ターン勝利
```

#### 注意点
- バリア中の駒には効かない
- 固定しても「覆う」ことは防げない
- 相手がLサイズで覆ってくる可能性を考慮

---

### 2.2 炎ライン：ひのこ

**効果**: 任意のトップ駒を持ち主の手札に戻す

#### ベストな使用場面

**パターン1: 防御駒の除去**
```
相手がリーチを防いでいるとき：
1. 別のマスに駒を配置して圧力
2. 防御駒を「ひのこ」で除去
3. 次ターンでリーチマスを取って勝利
```

**パターン2: 覆われた自分の駒の救出**
```
自分の重要駒が覆われたとき：
1. 新しい駒を配置
2. 覆っている相手駒を「ひのこ」で除去
3. 自分の駒が復活してリーチ成立
```

**パターン3: 相手のリーチ崩し**
```
相手がリーチ状態のとき：
1. 防御配置
2. リーチ駒の1つを「ひのこ」で除去
3. 危機回避 + 相手は再配置が必要
```

#### コンボ例
```
【除去 + 次ターン追撃コンボ】
盤面:  自 自 相(防御)
       _ _ _
       _ _ _

1. 中段左に駒を配置
2. 右上の防御駒を「ひのこ」で除去
3. 相手ターン：右上を再防御するか悩む
4. 自分ターン：右上 or 下段で勝利
```

#### 注意点
- 「まもる」中の駒には効かない
- 除去した駒は相手の手札に戻る（再利用される）
- 同ターンで除去したマスには配置できない

---

### 2.3 水ライン：まもる

**効果**: 自分の駒にバリア（覆われなくなる）を付与

#### ベストな使用場面

**パターン1: リーチ駒の保護**
```
リーチを作りながら守る：
1. 勝ち筋のマスにMサイズを配置
2. その駒に「まもる」を使用
3. 相手はLサイズでも覆えない → 次ターン勝利
```

**パターン2: 重要マスの確保**
```
中央など重要マスを取るとき：
1. Sサイズで中央を確保
2. 「まもる」でバリア
3. 相手はそのマスを奪えない
```

#### コンボ例
```
【Sサイズ + まもるコンボ】
盤面:  自 _ _
       _ _ _
       _ _ 自

1. 中央にSサイズを配置（斜めリーチ）
2. 即座に「まもる」を使用
3. 相手は中央のSサイズを覆えない
4. Sサイズでリーチが成立 → 次ターン勝利
```

#### 注意点
- バリアは次の相手ターン終了まで有効
- 自分でその駒を移動するとバリア解除
- 「やどりぎ」は防げない（移動不可になる）

## 3. マッチアップ別対策

### 3.1 草 vs 炎

| 草の強み | 炎の強み |
|---------|---------|
| 相手駒を固定して時間稼ぎ | 固定された駒も除去可能 |
| 防御的に戦える | 攻撃的に駒を排除 |

**草側の戦略**:
- 炎の「ひのこ」に備えて駒を分散配置
- やどりぎで固定しても除去される可能性を考慮
- 終盤まで能力を温存し、決定的場面で使用

**炎側の戦略**:
- 固定されても「ひのこ」で状況打開可能
- 相手の能力を先に使わせる立ち回り
- Lサイズを温存して覆い返しを狙う

---

### 3.2 草 vs 水

| 草の強み | 水の強み |
|---------|---------|
| バリア駒も固定可能 | Sサイズでも安全にリーチ |
| 相手の切り返しを封じる | 覆われない安心感 |

**草側の戦略**:
- バリア駒は固定して移動を封じる
- 相手がリーチ+まもるを狙う前に攻める
- 覆うことでバリア駒を無力化

**水側の戦略**:
- やどりぎを受けても覆われなければ安全
- リーチ+まもるのコンボを最優先
- 相手のLサイズの位置を常に把握

---

### 3.3 炎 vs 水

| 炎の強み | 水の強み |
|---------|---------|
| 駒を直接除去できる | バリアで除去を防げる |
| 攻撃的な展開 | 守りながら攻められる |

**炎側の戦略**:
- 相手が「まもる」を使う前に「ひのこ」で攻める
- バリア駒は覆うことで対処
- 相手の能力を誘発させてから本命の攻め

**水側の戦略**:
- 「ひのこ」を警戒して重要駒は即バリア
- 炎が能力を使った後は安全に展開
- Lサイズをバリアすると鉄壁

## 4. 上級テクニック

### 4.1 能力の「見せ札」効果

能力を持っているだけで相手の行動を制限できます。

```
例：水ラインの場合
- 相手は「まもる」を警戒してリーチを作りにくい
- あえて能力を使わず、プレッシャーをかけ続ける
- 相手が無理な攻めをしてきたところを反撃
```

### 4.2 覆いの連鎖を利用する

```
盤面:  S(自) _ _
       _ M(相) _
       _ _ _

1. 中央をLサイズで覆う（相手Mの上に自分L）
2. 相手が対応に困る
3. 能力で追い打ち
```

### 4.3 能力を使わない勝ち方

能力を温存したまま勝てる場面では、あえて使わないことも戦略です。

- 通常手段で勝てるなら能力は不要
- 相手に「能力を使わせる」ことで優位に
- 能力の有無が心理的プレッシャーになる

## 5. 序盤・中盤・終盤の指針

### 序盤（1〜3ターン目）

- **基本**: 中央か角を取る
- **駒選択**: M/Sサイズを先に使う
- **能力**: まだ使わない

### 中盤（4〜6ターン目）

- **基本**: リーチを作る or 相手のリーチを防ぐ
- **駒選択**: 状況に応じてLサイズ投入
- **能力**: 決定的場面なら使用検討

### 終盤（7ターン目以降）

- **基本**: 勝負を決めにいく
- **駒選択**: 残り駒で最善を尽くす
- **能力**: ここで使わないでいつ使う

---

## 6. よくある失敗と対策

### 失敗1: 能力の早撃ち
**問題**: 序盤で能力を使い、終盤で切り札がない
**対策**: 「この能力で勝てるか？」を毎回自問する

### 失敗2: Lサイズの早出し
**問題**: Lサイズを使い切り、覆い返せない
**対策**: 少なくとも1つは終盤まで温存

### 失敗3: 能力の対象ミス
**問題**: 効果的でない駒に能力を使用
**対策**: 「この駒を対象にする意味は？」を確認

---

## まとめ

1. **能力は1回限り** → 使いどころを見極める
2. **駒配置 + 能力** → コンボで相手を追い詰める
3. **マッチアップ** → 相手のラインに応じた戦略
4. **温存の価値** → 持っているだけでプレッシャー

勝利への道は「正しいタイミングで能力を使う」ことにあります。
練習を重ねて、最適な使いどころを見つけましょう！
